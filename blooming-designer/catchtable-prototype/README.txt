CATCHTABLE HTML PHONE PROTOTYPE

실행: index.html을 브라우저에서 열어주세요. assets 폴더와 CSS/JS 파일은 함께 유지합니다.
서버나 별도 패키지 설치 없이 실행되는 HTML, CSS, JavaScript 결과물입니다.

탐색 흐름
1. 홈 → 내 주변: 식당 저장, 필터 선택
2. 홈 → 마이다이닝 → 나의 예약: 방문예정/방문완료 전환
3. 방문완료 → 구름당의 예약하기 → 날짜·인원·시간 선택
4. 방문 목적/고객 요청사항 → 예약하기 → 새 예약이 추가된 내역 확인
5. 홈의 웨이팅 카드 클릭: 12번/2번 상태 변경

데스크톱: 왼쪽 바로가기와 처음부터 다시 버튼을 사용할 수 있습니다.
휴대폰/태블릿: 화면 크기에 맞춰 목업이 조절됩니다. 휴대폰 내부를 터치·스크롤합니다.
Esc: 이전 화면으로 돌아갑니다.

실제 예약/결제/웨이팅 접수는 발생하지 않는 디자인 프로토타입입니다.
원본에서 연결된 12개 화면의 흐름을 바탕으로 제작했습니다.
원본에서 연결되지 않은 메뉴는 추가 서비스 화면으로 확장하지 않았습니다.
